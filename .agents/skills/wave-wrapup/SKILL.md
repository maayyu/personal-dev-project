# wave-wrapup｜Wave完了判定のための証拠整理と引き継ぎ

## 目的・担当範囲

- Phase・Wave等の区切りで、**どこまで実施でき、何を根拠に完了を判断できるか**を整理する。
- リポジトリルートの `AGENTS.md` に従う。本Skillは `MODE` にかかわらず**読み取り・報告専用**。コード・テスト・WBS・設計書の変更、コミット・Push・マージ、ブランチ切替をしない。
- **最終的な完了承認と次のWaveへの移行判断はユーザー／PM** が行う。本Skillが自動で完了扱いにしない。
- 実行済みテストの証拠確認は `test-verify`、差分品質の評価は `self-review`、文書の更新は `doc-sync`、次の作業計画は `task-plan` の担当とする。

## 入力

- **対象**：Phase／Wave名、WBS ID・範囲、完了条件（既存の定義があればそれを優先）。
- **対象版**：確認対象ブランチ・コミット、関連PRやレビュー記録（分かる範囲）。
- **証拠**：実装ファイル、テスト実行ログ、レビュー結果、設計・WBS・決定記録、未解決課題。
- 完了条件が未定義なら勝手に新設せず、根拠に基づく暫定チェック項目として提案する。

## 手順

1. **対象範囲と終了条件を固定する**
   - `AGENTS.md` §3に従い、対象ブランチ・コミット・WBS・Wave記録・承認済み仕様を確認する。`main`に存在しないことを理由に実装ブランチの成果を否定しない。
   - 既存WBSに書かれたタスク、依存関係、完了条件を優先し、対象外の後続Waveタスクを勝手に完了条件へ追加しない。
   - WBS `.xlsx`、未追跡の作業記録等が読み取れない場合は、その証拠が未確認であることを明示する。
2. **成果と検証証拠を照合する**
   - **実装**：対象タスクごとのコミット済みコード・構成・Migration・未コミット変更を区別して確認する。
   - **テスト**：対象ケース、実行コマンド、実施日時・対象コミット、PASS／FAIL／ENV-BLOCKED／NOT-RUNを区別する。過去の報告しかなければ「報告ベース」とする。
   - **レビュー**：実施者／対象版、Critical・High等の未対応指摘、修正後の再確認状況を区別する。未実施レビューを合格扱いしない。
   - **文書・Git**：確定済み設計との相違、必要な記録の更新状況、意図しない差分や未追跡ファイルを確認する。未追跡ファイルを消したり、自動でコミットしたりしない。
3. **未完了・リスク・判断待ちを分離する**
   - 残作業を「完了を妨げる」「次Waveへ明示的に繰り越せる」「任意改善」に分ける。根拠なしの完了・未完了断定を避ける。
   - 仕様矛盾、データ整合性・セキュリティ上の重大な指摘、必要なテスト未実行、承認待ちを明示する。
   - 環境エラーによる検証不能は、テスト失敗とも成功とも扱わず、原因と影響範囲を区別する。
4. **完了判定案を示す**
   - `完了候補`：必要な条件が証拠で確認でき、重大な未対応課題がない。
   - `条件付き完了候補`：繰越可能な事項が明示され、承認を要するもの。
   - `未完了`：合意された必須条件が満たされていないと確認できる。
   - `判定保留`：重要な資料・結果が未確認で、完了可否を判断できない。
   - 判定の根拠と限界を述べ、**正式な完了承認の代行はしない**。
5. **次への申し送りを最小限にまとめる**
   - 引き継ぐ課題について、内容・影響・次の担当Skill／作業・確認条件を短く整理する。
   - `doc-sync` での文書反映、`test-verify` での追加検証、`self-review` での再レビューが必要なら提案し、実行や編集はしない。
   - 次Waveの最初の1手を示す。具体的なタスク分解は `task-plan` へ渡す。

## 出力形式

1. **対象・現在地**：Phase/Wave、WBS範囲、対象ブランチ・コミット、主要根拠。
2. **完了チェック**：実装／テスト／レビュー／文書・Gitの確認状況（確認済み・報告ベース・未確認を区別）。
3. **残課題・リスク**：ブロッカー、承認付き繰越、任意改善。
4. **PMへの判定案**：完了候補／条件付き完了候補／未完了／判定保留と理由。
5. **次Waveへの申し送り**：必要な追加確認と次の1手。

## 完了条件

- 対象範囲の成果と証拠、未確認事項が分かり、ユーザーが完了を判断できる。
- 未実行のテスト・未対応のレビュー・未追跡ファイルを隠していない。
- 完了承認・WBS更新・Git操作・コード編集を行っていない。
